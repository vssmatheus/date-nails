Dúvidas frequentes

Preciso instalar algum aplicativo?

Não. Tudo funciona no navegador. No celular você pode “Adicionar à tela inicial” e o painel vira um app.

Como o WhatsApp automático funciona?

Você conecta o WhatsApp do studio lendo um QR Code no painel, como no WhatsApp Web. As mensagens saem do seu número.

E se eu não renovar?

Sua página de agendamento fica pausada para as clientes, mas seus dados ficam guardados. É só pagar para voltar.

A cliente precisa criar conta?

Não. Ela só informa nome e WhatsApp. Para ver os agendamentos, usa o link que recebe no WhatsApp ou nome + número.
